# Agonomia Development Atlas

Public standalone tracker for the Agonomia project. The main Agonomia source repository remains separate and private.

## Publish with GitHub Pages

1. Create a public GitHub repository named `agonomia-development-atlas`.
2. Upload `index.html` and this `README.md` to the repository root, or push them using Git.
3. Open Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment to finish. The site URL should be `https://oracleofnodes-byte.github.io/agonomia-development-atlas/`.

The tracker is a standalone HTML file. Its 3D library is loaded from external CDNs, so visitors need internet access for that library.
